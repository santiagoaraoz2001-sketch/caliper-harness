Exact multiline ordinary prompts are a separate input qualification. Live `/btw` capture, persistence and next-model uptake remain distinct stages (RUN-001).

**Help finding corrected:** source `keyHelp()` already contains `ctrl+n/p switch tab`; `TestHelpShowsKeys` pages the overlay. The original trace did not show that scrolled section. Missing visibility in that capture is not a proven missing binding or help implementation. Live discoverability remains partial until the user journey is exercised.

- Decision disabled mode: readiness changes to human approval, not implicit authorization; `decision_disabled_test.go` and lifecycle-auth tests are component anchors.
- Persisted graph knowledge, styles and help: positive component roundtrips differ from spontaneous small-model retrieval/application. Graph uptake stays a separate E06/E07 benchmark measurement.
- Worker review/check claims: E03/E08 exact ownership and independent command receipts are tested separately from TUI display and are never inferred from “done”.
