# v0.2.2 release notes — local candidate

Caliper now provides searchable, linked project knowledge and concise design/code guidance through the existing GraphQL tool. The guidance is loaded on demand; project identity remains separately authored. Feature and architecture entries can point to each other and to source, with explicit missing-reference and source-freshness information.

Windows execution uses native Bash, preserves the Windows project/runtime context and propagates failed pipelines. File discovery handles native separators and returns reusable project locators. Direct task claims select the executing task, capacity recovery batches optional context reductions, and PAT questions stop repeating the full approach strategy. Unqualified model completion receives an explicit host outcome.

Prompt aliases work in Windows Git checkouts without symlink support. Changing a project's decision runtime no longer retains an incompatible omitted protocol from personal connections.

The release does not introduce another reviewer, tool family or workflow builder. File freshness is not verification. The Space Transporter benchmark has not been rerun and its defects have not been concealed by editing the game.

Local native build, changed-package checks, focused planning/search regressions and npm wrapper checks pass. Broad test qualification is incomplete: the full run package exceeded its aggregate timeout; several other fixtures use filenames or symlink privileges unavailable on this HP. See [the plan](v0.2.2-plan.md) for exact coverage and limits. Linux/macOS release builds, GitHub/npm publication and HP installation remain pending.
