# Forming a design language

## Brief to direction
Start with the person, task and setting: what must they understand, decide or feel, and under what reading, device and time constraints? Extract existing commitments before inventing a new look. A serious subject does not automatically imply black and gold; a playful subject does not automatically imply rounded cards.

Write one concrete proposition, such as "a field notebook for comparing observations" or "a precise instrument for monitoring changing conditions." Then derive rules from it. A notebook might use strong captions, numbered records, restrained ink colors and generous annotation margins. An instrument might use stable alignment, compact status bands, tabular numbers and immediate state changes. These are hypotheses to test on real content, not labels to paste over a generic template.

If direction is open, sketch two materially different compositions using the same representative content. Change organizing idea, reading sequence and asset treatment, rather than merely swapping palettes. Compare how quickly each explains the primary task, how much content it handles, and whether it fits the audience. Choose a reasoned direction or ask the user about the unresolved preference. Do not make a second clarification ritual when the user has delegated taste.

## Translate into rules
A useful identity is a small set of decisions another contributor can apply: type roles and fallbacks; semantic colors; spacing and density; grouping and border treatment; corner and elevation roles; icon/asset character; motion purpose; and component states. Include examples of what to do and avoid. "Premium, modern, polished" cannot resolve a new screen.

Record the selected rules under the project identity with their reasons. Add a representative specimen: a content-rich section, primary action, secondary action, error, empty state and narrow layout. Use shared tokens where repetition warrants them. A one-off visual flourish need not become a universal component. Preserve existing decisions when changing one feature; record deliberate exceptions next to that feature.

## Originality with purpose
Creativity comes from noticing the subject's particular structure: a time sequence, a geographic relationship, an object, a ritual or an unusual comparison. Use that structure in the composition, imagery or interaction. Remove decorative motifs that would fit any unrelated product. Familiar controls can support an original visual world.

Ask of each conspicuous treatment: what meaning or hierarchy does it add? Repeated equal-radius containers, soft glows, blurred glass and oversized marketing headlines often erase distinctions when applied everywhere. Replace them with a decision: aligned rows for comparison, an inset for a quote, a hard divider for a section, or a distinctive illustration for a central idea. Rounded corners and glow remain legitimate when their purpose fits the design; replacing one fashionable preset with another is not creativity.
