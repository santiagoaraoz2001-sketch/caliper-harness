# Color, material and emphasis

## Palette
Build color roles from the direction: canvas, surface, primary text, supporting text, accent, selected state, and status. Start with a restrained neutral structure and one meaningful accent. Derive hue and saturation from the subject or existing brand, then compare actual content on it. A palette name such as "ocean" or "luxury" does not specify readable states.

Use accent sparingly enough to retain meaning. A primary action, selection and urgent warning should not all appear identical. If categories use color, retain a label, shape or position that explains them without color perception. Positive and negative values need a clear sign or text as well as hue.

[See a restrained operational palette](knowledge:caliper/guides/ui/instrument-example#material-and-state)

## Material
Assign borders, radius, shadow and transparency roles. A subtle divider can separate adjacent records; elevation can distinguish a temporary overlay; a rounded thumbnail may belong to an organic visual language. Applying the same rounded rectangle, hairline border and soft glow to every group creates an undifferentiated surface.

When a treatment feels generic, identify the missing distinction. Use open typography for a reading section, a solid band for navigation, a crisp inset for a quoted object, or a purposeful diagram. Do not add more effects to compensate for weak composition. A gradient is useful when it conveys atmosphere, depth or an intentional brand motif; it need not appear on every button.

[Choose assets that carry the concept](knowledge:caliper/guides/ui/assets#choice)

## States and verification
Build a small state specimen with normal, hover, focus, selected, disabled, loading, warning and error examples. Preserve legibility and state distinctions across the actual background. A translucent overlay must be evaluated over its underlying content, not against an assumed solid color. Disabled controls still need readable meaning and an explanation when their availability is important.

Inspect the rendered surface in the supported themes and adverse content states. Check contrast using the actual composited colors where possible, and check focus indicators against adjacent colors. A computed ratio from two CSS tokens does not verify text over photography. Keep critical text on a controlled surface or adjust the asset treatment.
