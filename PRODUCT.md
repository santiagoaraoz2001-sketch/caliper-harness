# Caliper Harness

By Specific Labs. A terminal coding workspace built for small local models.

## Register

product

## Users and purpose

Developers using local models in a terminal to inspect code, carry out coding work, follow tools and observed file changes, manage existing workflows, and inspect runtime state.

## Brand and references

Specific Labs: precise, calm, capable. Preserve the mint identity. Owner references inform bold action labels, readable code, quieter metadata and shaded differences. Specific Labs mint supplies the product identity and paths; Blueprint state and syntax colors come from the actual project tokens.

## Principles

Preserve existing commands and bindings. Keep complete recorded commands and outputs available. Never label a tool invocation successful before an actual receipt. Keep selected items and controls visible at narrow sizes. Preserve the composer, drafts, sessions, ownership, and source/quote fidelity.

## Accessibility

Keyboard operation, width-aware wrapping, meaningful labels with color, NO_COLOR, and real 80x24 and 120x40 frames. Do not manufacture per-role font sizing in a preview; use the terminal's real weight, italic and color capabilities.
